# Облік витрат на харчування

Ідея проста: записувати, що купив поїсти і скільки це коштувало, а потім дивитися,
скільки грошей пішло на їжу за день, тиждень чи місяць.

## Що де лежить

- `spec/` — ідея системи, потім тут буде специфікація
- `src/` — код
- `tests/` — тести
- `docs/` — документація і звіти
- `logs/` — записи про роботу з агентом і прийняті рішення

Префікс показує, що саме змінилося:

- `spec:` — ідея, вимоги, специфікація
- `test:` — тести
- `feat:` — нова функціональність у коді
- `docs:` — документація
- `log:` — записи в `logs/`
- `gate:` — контрольна точка або злиття, де вирішувався конфлікт
- `chore:` — службове (структура, .gitignore)

`main` — основна гілка. Кожну зміну роблю в короткій окремій гілці
(`docs/...`, `spec/...`, `agent/...`), дивлюся `git diff` і зливаю в `main`.
