вважається перевіреною лише тому, що її сформував кодинговий агент. Тому всі
команди з README виконані в чистому середовищі, а не прочитані очима.

Виконав: Майстренко Ілля, група КН-32. Дата: 16.11.2026.

## Як перевірялося

Створено копію репозиторію без `.venv`, без `data/`, без кешів і без робочих
журналів — тобто рівно те, що отримує людина після `git clone`. У ній
виконано кожну команду README по порядку, згори вниз, без жодної дії, якої
немає в тексті.

Середовище перевірки: Linux, Python 3.13, порожній каталог. Окремо перевірено
те, що стосується Windows: наявність `tzdata` в залежностях — без нього
запуск падає з `ZoneInfoNotFoundError`, і саме так було на початку ЛР5.

## Знахідка 1: команда зміни порту не працювала

README пропонував для іншого порту запускати сервер напряму:

```
python -m uvicorn food_expenses.api.app:create_app --factory --port 9000
```

Фактичний результат:

```
ModuleNotFoundError: No module named 'food_expenses'
```

Причина. Проєкт не встановлюється як пакет; каталог `src` додає до шляху
імпорту сам `run_server.py`. Коли `uvicorn` запускається напряму,
`run_server.py` не виконується, і шлях лишається без `src`.

Команда була правдоподібною на вигляд і не працювала жодного разу. Прочитати
це в тексті було неможливо — тільки запустити.

**Виправлення.** Можна було дописати в README встановлення `PYTHONPATH`, але
це дві різні команди для Windows і для Linux, і обидві легко набрати
неправильно. Натомість `run_server.py` отримав аргументи `--host` і `--port`:

```
python run_server.py --port 9000
python run_server.py --host 0.0.0.0 --port 9000
```

Одна команда, однакова на всіх системах. Перевірено фактичним запуском:
сервер піднявся на порту 9000, `GET /api/v1/profiles` повернув 200.

Заразом у README з'явилося пояснення, чому адреса за замовчуванням саме
`127.0.0.1`, а не `0.0.0.0`: система працює з особистими витратами.

## Знахідка 2: мертва директива `noqa` у конфігурації Sphinx

`ruff check .` у чистому середовищі дав одне зауваження:

```
RUF100 Unused `noqa` directive (non-enabled: `A001`)
docs/sphinx/conf.py:24
```

У рядку з `copyright` стояла директива `# noqa: A001`, що подавляє правило з
набору `flake8-builtins`, якого конвенція не включає. Директива нічого не
подавляла.

Це вже другий такий випадок у роботі: перший був у `logging_setup.py` з
`# noqa: A003` і описаний у `logs/convention-audit.md`. Обидва — мій
недогляд, обидва знайшло правило `RUF100`, яке й існує для пошуку подавлень,
що нічого не подавляють.

Директиву прибрано. `ruff check .` у чистому середовищі проходить без
зауважень.

## Висновок

README перевірено не читанням, а виконанням, і це дало два дефекти, яких
читання не дало б: команда, що виглядала правильно й не працювала, і мертва
директива в конфігурації, яку не помічали три етапи роботи поспіль.

Перший дефект виправлено не в тексті README, а в коді: замість того, щоб
документувати обхідний шлях із `PYTHONPATH`, запускач отримав аргумент
`--port`. Документація має описувати зручну систему, а не пояснювати, як
обійти незручну.
