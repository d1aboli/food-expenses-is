# Глосарій предметної області

Терміни з цього списку використовуються однаково в специфікації, сценаріях, тестах, коді,
повідомленнях інтерфейсу та в повідомленнях комітів.

| Термін | Визначення |
|---|---|
| **Профіль** | Іменований набір даних однієї людини: її покупки і її категорії. Обирається зі списку на старті, пароля не має |
| **Покупка** | Запис про витрату на харчування: назва, категорія, ціна за одиницю, кількість, дата й час |
| **Назва покупки** | Текстовий опис того, що куплено. Обов'язкове поле, не може бути порожнім |
| **Ціна за одиницю** | Вартість однієї одиниці товару в гривнях (за штуку або за кілограм). Більша за нуль |
| **Кількість** | Скільки одиниць товару куплено. Може бути дробовою (0,7 кг). Більша за нуль |
| **Вартість покупки** | Ціна за одиницю, помножена на кількість, заокруглена до копійок |
| **Категорія** | Тип витрати. Базові: продукти, ресторан, доставка, напої, інше. Профіль може додавати власні |
| **Базова категорія** | Категорія, створена системою при створенні профілю. Перейменовується, але не видаляється |
| **Непорожня категорія** | Категорія, до якої належить хоча б одна покупка профілю |
| **Календарний день** | Доба з 00:00 до 23:59 |
| **Календарний тиждень** | Період з понеділка по неділю включно |
| **Календарний місяць** | Період з 1-го по останнє число місяця включно |
| **Довільний діапазон** | Період між двома датами, які обрав користувач, включно з обома |
| **Підсумок за період** | Сума вартостей усіх покупок профілю, дата яких належить періоду |
| **Розбивка за категоріями** | Таблиця «категорія — сума — частка у відсотках» для обраного періоду |
| **Журнал прогону тестів** | Файл у `/logs` із датою прогону та кількістю тестів: усього, успішних, неуспішних |
| **Журнал сесії агента** | Файл у `/logs` із запитом до агента, переліком змінених файлів і рішенням людини |
| **Вимога** | Твердження про поведінку або властивість системи зі стабільним ідентифікатором REQ-F-XXX або REQ-NF-XXX |
| **Критерій прийняття** | Спостережувана умова, за якою перевіряється виконання вимоги |
| **Сценарій** | Опис поведінки у формі Given–When–Then |

## Терміни, яких свідомо уникаємо

- «Транзакція», «витрата», «чек» — використовується лише **покупка**.
- «Користувач системи» у значенні облікового запису — використовується **профіль**.
- «Сума покупки» у значенні ціни за одиницю — ціна і вартість розрізняються завжди.
